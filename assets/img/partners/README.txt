Drop partner logo files here.

Best results:
- SVG, or PNG with a transparent background
- Roughly landscape or square; they're auto-sized (max ~52-56px tall)
- Name them simply, e.g. acme.svg

Then reference the file in content/partners.js:
  logo: "assets/img/partners/acme.svg"

Logos show in greyscale in the homepage scrolling strip and turn full-colour
on hover (matching the CISSA-style treatment). On the Partners page they show
full-colour. Any partner with no logo set falls back to an initials badge.
